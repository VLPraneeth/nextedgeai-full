# V1 Workspace Override

The V1 workspace inherits `../MASTER.md` with these focused application overrides.

- Keep the premium warm ivory, ink, and antique-gold system already used by the landing and authentication pages.
- Use a compact guided-workflow layout: one outcome statement, live readiness metrics, five sequential stages, and one AI mapping action.
- Prefer clear status text over decorative charts. Color must never be the only status indicator.
- Use Playfair Display only for the primary workspace heading; use Inter for operational content and controls.
- All actions must be at least 44px high, keyboard accessible, visibly focused, and responsive at 375px without horizontal scrolling.
- Show loading and inline failure states for live API checks and AI requests. Do not use continuous decorative animation.
